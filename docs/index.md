## 프로젝트 개요

본 프로젝트는 **실제 클라우드 침해사고 사례**와 **현업 인프라 아키텍처**를 분석하여,
**비용 최적화된 보안 아키텍처**를 설계하는 것을 목표로 합니다.

단순한 이론이 아닌, 실제로 발생한 보안 사고들을 학습하고 현업에서 검증된 아키텍처 패턴을 참고하여
규모별로 적용 가능한 실용적인 보안 설계를 제시합니다.
